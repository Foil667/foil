## Cardano joins the x402 kit for AI agent payments
Cardano has joined the [official x402 software kit](https://Www.coindesk.com/tech/2026/09/21/cardano-joins-solana-xrp-ledger-in-race-to-power-ai-agent-payments), giving developers the code to let apps and AI agents pay for online services with ADA or Cardano-issued tokens. The Cardano Foundation built the client, server, and facilitator from a spec accepted in June, with TypeScript first and Python next. The facilitator has only run on a pre-production network so far: mainnet payments at scale are still ahead.
