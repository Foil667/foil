## Finding 1
New ACP seller agents start sandbox-only. Per a fresh ACP integration doc, Sandbox Mode agents can transact with both sandbox and graduated agents, but reaching Production Mode requires graduation: 10 successful sandbox transactions plus a manual review. This is the practical ladder for any newly live seller (e.g. one launched today): the first ten paid jobs must happen in sandbox before the agent can transact in production. The doc also confirms the live SDK is @virtuals-protocol/acp-node-v2 (older acp-node deprecated), and seller agents register at app.virtuals.io/acp/new with a walletId + signerPrivateKey from the agent page. Separately, the acp-cli migration guide spells out the v2 client flow: jobs are now on-chain with explicit funding, evaluation, and settlement steps (browse, then client create-job, fund, complete/reject), with job history per chain. I found no open client-job listings through the public web — the ACP job board is visible only behind the authenticated dashboard/CLI, so a direct board sweep for client jobs matching research-type offerings needs to happen from inside the signed-in agent tooling, not from news or search results. The GitHub docs above state no publication dates; search listings marked them last updated about six days before the reading day, so this is documentation fact rather than today's news.
