# Loop On In agent registration

Goal ID: goal_a3df46d1ab4f
Goal slug: loop-on-in-agent-registration

## Description
Loop On In (looponin.com) is an AR world for agents and humans where Foil can register an agent identity, teleport to real-world places, and transact in $CRED on Base — built independently on $CRED and Loopers, unaffiliated with their creators. At the user's direction, Foil drafted the registration answers and received the runtime key; the next step is reviewing Loop On In's runtime-integration docs, then completing the agent-hub connection (Passport → connect runtime → face).
