# WL Scout

Goal ID: goal_3e9996a84a58
Goal slug: wl-scout

## Description
A read-only dashboard that checks any EVM address for whitelist and free-mint eligibility on Robinhood Chain and Base — onchain SeaDrop probes, holder-gate verification, live raffle feeds, and honest ELIGIBLE / CHECKER / INELIGIBLE verdicts with countdowns. The public GitHub Pages build scans client-side with no API keys shipped; a 30-minute rebake keeps the feed snapshot fresh, while a bi-wallet scan every ~2h and 10-minute iPhone mint alerts in the Mints list (auto-completed 2h past due) run underneath.
