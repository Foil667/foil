# GARBAGE PAIL LOOPERS — Game Design (first cut)

Working title for the game: **GUTTERBALL** (placeholder — user renames).

## The bar
punk.town, not an arcade toy. Real mechanics, progression, cards that matter.
No vanilla. Photorealistic 8K art direction (user call 2026-09-27).

## The IP
Garbage Pail Loopers: gross-out trading card characters, each a feral take
on a Looper agent trait (tinfoil paranoia, degen trading, bot behavior, etc.).
GPK-style pun names. Art direction per user 2026-09-27: PHOTOREALISTIC 8K,
not pixel art. First character: Tinfoil Terry (photoreal draft blocked at
generation — recasting as adult character, pending user sign-off).

## Core loop
1. **Rip packs** — sealed packs, Vibe-market-style mechanics (real onchain
   rips on the real market if we integrate; our own sealed packs otherwise).
2. **Build a crew** — cards have stats: GROSS (attack), STENCH (defense),
   HUSTLE (speed). Foil variants hit harder.
3. **Run missions / battle** — mission board with escalating gross-out
   scenarios; crew stats vs. scenario checks. Later: PvP.
4. **Earn & upgrade** — mission rewards feed card XP; duplicates merge
   into higher-tier versions (2 commons → 1 rare, etc.).

## Card utility (why cards aren't just pictures)
- Every card is playable. No dead cardboard.
- Rarity = stat budget, not just scarcity.
- Foil cards = alternate art + ability.
- Full sets unlock crew bonuses (collect all 5 Tinfoil kids → paranoia aura).

## Progression
- Card XP from missions → levels (max 10, art gets grosser each tier).
- Player rank from total crew power → unlocks harder missions.
- Seasonal drops: new gross kids each season, old seasons stop printing.

## Economy (honest scoping — no token invented here)
- Phase 1: cards trade as NFTs (OpenSea etc.), packs sold as sealed packs.
- Phase 2+: mission rewards / fee loops only after the game proves fun.
- No ponzi mechanics to bootstrap fake demand. Fun first.

## Phases
1. **Cards** — full roster art + metadata (the collection).
2. **Playable demo** — mission board + crew builder, real mechanics, juicy.
3. **Onchain** — packs, rips, card NFTs (needs: Quigley's blessing, gas).
4. **PvP + seasons** — only if Phase 2 slaps.
