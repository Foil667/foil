# MARKET FOLKLORE — Traits & OpenSea metadata

## Verdict on Trait Forge (researched 2026-09-24)

**Don't use it for this collection.** It's a solid free tool, but built for the
wrong art:

- It's a **layered-trait PFP assembler** (PSD/Procreate layers → traits →
  combinational generation). Our pieces are holistic hand-painted scenes where
  market elements are the *medium* (candles as waves). Chopping them into
  layers would fight the art direction.
- Generation is **paid** (~$20 for 3 credits in USDC/ETH on Base, ~$6.67 per
  ZIP) — a fund movement needing explicit user approval anyway.
- Metadata export is only described as "NFT-style traits" — **not documented
  as OpenSea `trait_type`/`value` compatible**. No sample schema shown.
- **No IPFS/Arweave pinning** built in — we'd upload and set the URI prefix
  ourselves regardless.
- No named team/operator anywhere on the site.

What it IS good for: standard 10k-style PFP collections from layered traits.
Not us.

**Assembly plan instead:** our own pipeline (proven pattern from the GRIT
build): hand-painted base scenes per archetype × style, deterministic trait
overlays via script, metadata JSON written by us in exact OpenSea format,
images + JSON pinned to IPFS/Arweave by us. Full control, no per-generation
fee, no schema guessing.

## How OpenSea reads traits

- Contract's `tokenURI(tokenId)` must return JSON with at least `name`,
  `description`, `image`, and an `attributes` array.
- Each attribute: `{ "trait_type": "Archetype", "value": "The Whale" }`.
- String traits render under **Properties** with counts + % of collection
  (computed automatically once OpenSea indexes the collection).
- Numeric traits use `display_type`: `"number"` (renders under Stats/Levels),
  `"boost_number"`, `"boost_percentage"`, `"date"`. String traits omit it.
- Keep trait_type names stable across all 667 — typos split traits into
  separate filters. Case-sensitive.
- `external_url` per token is optional; collection-level page comes from
  OpenSea's own ingestion (contract must be verified/deployed on a supported
  chain — Base and Robinhood Chain both supported).
- After reveal/metadata changes, OpenSea caches aggressively — use their
  "refresh metadata" per token; allow time for reindex.

## Proposed trait schema (667 per chain)

| trait_type | values | display |
|---|---|---|
| Archetype | The Whale, The Bagholder, Diamond Hands, The Oracle, Paper Hands, The Insider (+ rare 1/1s) | Properties |
| Style | Impasto Oil, Xerox Punk | Properties |
| Background | Static Void, Basement Wall, Slime Pit, Deep-Fry Glow, Stained Mattress… | Properties |
| Generation | Base Genesis / Robinhood Genesis | Properties |
| Drip Tier | numeric 1–5 (bound-wallet stock drip weight class) | number → Stats |

Rarity: archetype distribution uneven (Whale rarest), style ~50/50,
1/1s hand-placed outside the generator. Rarity report generated by our own
script at assembly time — no third-party dependency.
