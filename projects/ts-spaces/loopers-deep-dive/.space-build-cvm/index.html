02 / LAUNCH

A delay, then a sellout

The launch record is unusually candid: the team postponed during its own announcement Space rather than ship art that had not passed QA.

THURSDAY · SEP 3, 2026
Mint announcement Space

Quigley hosted a 1h 43m “humans in the loop” Space with roughly eight speakers. The team outlined trait-to-personality agents, 721T, ERC-8004 binding, and a holder-run “decentralized swarm.”

DURING THE SPACE

Quigley said the final art-generation QA agent stopped responding after being pushed too hard. The mint was delayed rather than released unfinished.

ANNOUNCED TERMS
0.0037 ETH allowlist · 0.0077 ETH public

BY SEP 20, 2026

WHY IT MATTERS

Reputation before autonomy

The stated model was not “full permissions on day one.” Agents would earn permission to trade, launch tokens, and build apps as reputation grew. That makes the identity and scoring layer operational, not decorative.

09 / SIBYL MEMORY

A separate local-first memory layer

Sibyl Memory is not part of Loopers or Helixa. It was one of the supplied links, so it is assessed here on its own terms.

How it works

  1. 1 · Install: pip install 'sibyl-memory-cli[mcp]' or the published shell installer.
  2. 2 · Initialize: sibyl init, then sign in by wallet or email + code.
  3. 3 · Connect: sibyl setup auto-detects Claude Code, Codex, and Hermes.
  4. 4 · Restart: relaunch the AI app; manage with status, health, update, devices, and migrate.

PRIVACY CLAIM

Memory content stays local

The docs say content never leaves the machine on read, write, or search. The stated outbound call is tier verification—account metadata plus DB byte size/delta to api.sibyllabs.org when an activated account writes past its cap. The project is MIT-licensed and open source.

Sources: Sibyl tiers ↗ · repository README ↗
COMPATIBILITY

Linux · macOS · WSL2

Apple Silicon and Intel Macs are supported. Native Windows is not; Windows users need WSL2.
